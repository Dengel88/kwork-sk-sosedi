# СК «СОСЕДИ» (Иркутск) - Живой прототип всех 10 доработок сайта sk-sosedi.ru

Интерактивная демонстрация обновленных модулей для самописного сайта `sk-sosedi.ru`:
1. Фильтр проектов домов по этажности, площади и бюджету + уникальные карточки вместо повторяющихся заголовков «Дачный дом».
2. Клик по карточке дома -> модальное окно с галереей планировок и переключением **3 комплектаций с ценами** («Теплый контур», «Предчистовая», «Под ключ для сибирской зимы»).
3. Блок видеообзоров построенных объектов (по механике `plusdacha.ru`).
4. Блок получения PDF-каталога проектов + обновленный пошаговый квиз расчета сметы + ИИ-помощник по выбору сечения бруса под климат Иркутской области.
5. Карта сданных объектов (Иркутск, Хомутово, Байкальский тракт, Шелехов) и чистый мобильный адаптив (в духе `karkas-k.ru`).
